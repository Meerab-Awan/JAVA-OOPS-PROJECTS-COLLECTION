# Java OOP Projects Collection 🚀

A structured collection of Java applications built to demonstrate core Object-Oriented Programming (OOP) principles, memory management concepts, and clean code architecture.

## 📂 Projects Overview

### 1. Bank Account Management System 💳
* *Core Concepts:* Encapsulation, Parameter Shadowing (this), Copy Constructors, and Custom Objects as Method Return Types.
* *Description:* A Java application simulating core banking operations. It maintains private account states, processes updates via encapsulation, and generates immutable snapshot transaction receipts using copy constructors and object references.
